# Limitations

AMFCA deliberately distinguishes reproducibility from validation. The Lhende case study contains internally audited multisensor candidates, but field-level geomorphic/process validation was unavailable for the priority patches. CEMS mapped products did not cover the priority candidates, and the configured Landsat audit did not yield suitable same-platform/same-track pre/post pairs. These are data-availability limitations, not negative validation.

The generic mode does not automatically generalize the complete upstream Earth Engine classification to every basin. New studies must validate acquisition windows, orbit pairing, terrain effects, thresholds, ancillary datasets and geometry.
